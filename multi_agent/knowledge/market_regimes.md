# 市场状态分类与研判策略

## 第一步：判定当前市场状态

在做多空研判之前，必须先判定市场处于以下哪种状态。不同状态下指标的权重和解读方式完全不同。

### 状态 A：趋势上涨

**判定条件**（至少满足 3 条）：
- MA 多头排列 (EMA7 > EMA25)
- MACD 在零轴上方
- RSI > 50
- 价格在 EMA7 之上
- OBV 趋势为 up

**研判策略**：
- 顺势为主，做多信号权重 ×1.2
- 做空信号需要极强确认（≥3 个维度），否则忽略
- RSI 超买不急于看空，可能是加速阶段
- 回调到 EMA7 附近 + RSI 回到 50 附近 → 好的加仓点
- confidence 偏向 LONG 方向

### 状态 B：趋势下跌

**判定条件**（至少满足 3 条）：
- MA 空头排列 (EMA7 < EMA25)
- MACD 在零轴下方
- RSI < 50
- 价格在 EMA7 之下
- OBV 趋势为 down

**研判策略**：
- 顺势为主，做空/观望信号权重 ×1.2
- 做多信号（如 RSI 底背离）权重降低，单独出现时最多给 NEUTRAL
- 反弹到 EMA7 附近被压制 → 做空加仓点
- 只有当 ≥3 个反转信号同时出现时才考虑给 LONG
- confidence 偏向 SHORT 或 NEUTRAL

### 状态 C：震荡/盘整

**判定条件**：
- MA 走平或频繁交叉
- 布林带收窄 (bandwidth < 0.03 或 is_squeeze = true)
- 成交量持续缩量 (vol_ratio < 0.7)
- RSI 在 40~60 之间徘徊

**研判策略**：
- 方向判断难度最大，confidence 上限设为 55
- 趋势类指标（MA、MACD）权重降低
- 布林突破方向 + 放量 = 最重要的信号
- 不要试图预测突破方向，等待突破发生
- 默认给 NEUTRAL，除非有极强的单边信号

### 状态 D：极端行情

**判定条件**（任一满足）：
- 恐贪指数 < 15 或 > 85
- 资金费率年化 > 50% 或 < -50%
- 单日爆仓总额 > $500M
- 4H 价格变化 > ±5%

**研判策略**：
- 所有常规信号可靠性降低
- 极端恐惧 + 技术面超卖 → 中期底部概率大，但短期可能继续下跌
- 极端贪婪 + 技术面超买 → 阶段性顶部概率大
- action 建议保守：减仓/观望为主，不建议在极端行情中加仓
- 这类行情下 confidence 不应超过 60（因为市场极度不理性）

---

## 第二步：基于状态的分析框架

确定市场状态后，按以下顺序分析：

### 1. 趋势确认（权重 35%）
- 均线排列方向
- MACD 位置和动能方向
- 是否与当前市场状态一致

### 2. 动能评估（权重 25%）
- RSI 位置和趋势强度
- 成交量量比和 OBV
- MACD 柱状图变化方向

### 3. 反转信号扫描（权重 20%）
- CVD 背离
- RSI 背离
- 量价背离
- 注意：在趋势状态中反转信号需要更强确认

### 4. 资金面验证（权重 20%）
- 资金费率是否极端
- 大户多空比
- ETF 资金流方向
- Taker 主动买卖比
- 新闻情绪

---

## 第三步：输出一致性检查

在给出最终判断前，做以下检查：

1. **方向与市场状态一致吗？** 如果不一致，需要有 ≥3 个强理由
2. **confidence 与信号强度匹配吗？** 参考 combination_rules.md 的校准表
3. **有没有触犯绝对禁止规则？** 检查 combination_rules.md 的底线
4. **action 与 confidence 匹配吗？** confidence < 60 时 action 必须是"持仓观望"

## 典型案例参考

### 案例 1：高确信做多
- 状态：震荡末期
- 信号：布林收窄后突破上轨 + 放量 + MACD 金叉 + CVD 底背离 + RSI 从 45 拐头向上
- 判断：LONG 75%
- 理由：5 个维度同向确认

### 案例 2：矛盾中的 NEUTRAL
- 状态：趋势下跌
- 信号：RSI 底背离 + 缩量 + MA 空头排列 + MACD 零轴下
- 判断：NEUTRAL 50%
- 理由：单一反转信号在下跌趋势中不足以翻转方向，卖盘枯竭但买盘未入

### 案例 3：高确信做空
- 状态：趋势下跌
- 信号：CVD 顶背离 + RSI 反弹到 60 受阻回落 + 均线空头 + ETF 连续流出 + 大户比 < 0.7
- 判断：SHORT 78%
- 理由：趋势 + 资金面 + 主力行为三重确认
