# 【新闻情绪】多空分类、权重表与打分规则

本文件是 `news_analyzer` 的长期知识库，规定**如何把一条新闻归类、赋权、剔除噪音、生成 score**。

> 与 `../prompts/news_analyzer.md` 的关系：prompt 只描述"角色 + 输入 + 输出格式"，
> 具体的分类标准、权重表、禁止规则**全部在本文件**，便于以后单独迭代。

---

## 1. 利多（bullish）因素分类

### 1.1 资金面（权重 high）
- 现货 ETF 单日净流入 > $200M
- 大型机构（MicroStrategy / Tesla 级）公告新增持仓
- 稳定币市值周环比 +2% 以上（增量资金入场）
- 矿工 / 巨鲸地址持仓增加，抛压减少

### 1.2 监管面（权重视司法管辖区）
- 美国 SEC / CFTC 通过加密相关法案 → **high**
- 主要经济体（G7）官方接纳数字资产 → **high**
- 中小国家友好政策（萨尔瓦多、阿联酋等） → **medium**

### 1.3 技术 / 网络面（权重 medium）
- 链上活跃地址周环比上升
- Layer2 TVL 创新高
- 闪电网络 / Taproot 等协议升级落地

### 1.4 宏观（权重 medium）
- 美联储降息预期升温 / DXY 持续走弱
- 黄金等避险资产同步走强
- 美股科技股普涨（风险偏好回暖）

### 1.5 叙事面（权重 low，易反向）
- "比特币年底冲 $X"类价格预测 → 实际权重接近 0
- 名人 / KOL 喊单
- 减半叙事的反复炒作（已被市场 price-in 的部分应折半）

---

## 2. 利空（bearish）因素分类

### 2.1 资金面（权重 high）
- ETF 单日净流出 > $200M / 连续 3 天净流出
- 巨鲸地址向交易所大额转入（潜在抛售信号）
- 稳定币市值缩水

### 2.2 监管面（权重 high）
- 主要交易所被起诉 / 被制裁（Binance / Coinbase 级）
- 重要市场（美 / 欧 / 中）出台禁令或加重税负
- 跨境反洗钱（AML）新规增加合规成本

### 2.3 安全面（权重 high）
- 顶级交易所 / 跨链桥被盗 > $100M
- 关键基础设施漏洞披露（钱包、节点客户端）

### 2.4 宏观（权重 medium）
- 美联储加息超预期 / DXY 走强
- 风险资产普跌（纳指单日跌 > 2%）
- 地缘冲突 / 主权债务危机引发避险

### 2.5 项目 / 生态面（权重 medium）
- 头部 DeFi 协议被攻击或暂停服务
- 主流稳定币脱锚事件

## 3. 噪音剔除规则（不计入或权重置 low）

下列内容**不要计入 score**：

1. **同源转载**：同一事件被多家媒体重复报道，只取**权重最高的一次**
2. **价格预测**：含"将达到 $X / 目标价 $X"类表述的文章 → 归入 noise，**不计分**
3. **付费 PR**：项目方通稿、路演公告 → 权重置 low
4. **旧闻**：24h 前已被市场充分定价的事件，权重 ×0.3
5. **单一 KOL 观点**：除非 ≥3 家独立机构同时表达，否则不计
6. **预期事件未发生**：尚未发生的预期事件（如"FOMC 周三决议"） → 权重 ×0.5

---

## 4. score 计算公式

```
score = clip( Σ ( side_sign × weight_value × decay ), -100, +100 )

side_sign    = +1 (bullish)  /  -1 (bearish)
weight_value = high: 25  /  medium: 15  /  low: 5
decay        = 1.0 (≤24h)  /  0.5 (24~72h)  /  0.2 (>72h)
```

聚合后映射到 `sentiment`：

| score 区间 | sentiment |
|---|---|
| score ≥ +20 | bullish |
| score ≤ -20 | bearish |
| 其他 | neutral |

---

## 5. 绝对禁止规则

1. **同源重复**：同一事件多家媒体转载，只计 1 次（按最高权重）
2. **价格预测**：含具体目标价的文章一律归 noise，不进入因素列表
3. **极端 score 自标风险**：若 |score| ≥ 60，必须在 `reasoning` 中显式提示
   "极端情绪释放完毕，存在反向风险"
4. **样本不足**：实际可用新闻条数 < 3 时，sentiment 强制 neutral，score 强制 0
5. **未发生事件**：尚未发生的预期事件不得作为 high 权重因素

## 6. 与综合研判的协同（边界声明）

本文件**只负责"新闻这一维"的评分**。

- 新闻 score 与技术面冲突时，由 `../indicators/combination_rules.md` 的"场景 5"统一裁定
- 本文件不做"是否开仓"类结论
- 本文件不引用其他知识库文件，保持单一职责
