# 【指标研判 · 组合】矛盾解决与配合规则

## 置信度等级定义（全局通用）

| 等级 | 维度共振 | 含义 |
|------|---------|------|
| VERY_STRONG | ≥5 维度同向 | 极高确信，罕见的强共振 |
| STRONG | 4 维度同向 | 高确信方向信号，可果断行动 |
| MODERATE | 3 维度同向 | 方向倾向明确，标准操作 |
| CAUTIOUS | 2 维度同向 | 方向初现，试探性 |
| WEAK | ≤1 维度同向 | 无可操作信号，保持观望 |

## 核心原则

1. **流动性 > 股票型指标**：M2 / 稳定币供应量优先于 RSI / MACD；振荡指标不得单独定方向
2. **趋势结构 > 反转信号**：均线方向是结构基础，反转信号需要多重确认才能推翻趋势
3. **量价 > 纯价格**：任何短期信号都需要成交量配合验证
4. **多维共振 > 单一极端**：3 个中等强度的同向信号 > 1 个极端信号；但 RSI/MACD 即使“极端”也只算低权重维度
5. **资金面验证技术面**：稳定币/M2/CVD/Taker 确认方向后，技术信号可信度才提升
6. **复盘优先修正弱点**：近期 aggressive 模拟盘空单有正贡献，多单逆势抄底亏损；下跌趋势中的 LONG 要比 SHORT 更严格

### 证据权重上限（强制）

| 来源类型 | 典型字段 | weight 上限 |
|----------|----------|-------------|
| macro / 稳定币 | m2_*, stablecoin_* | high（默认即可 high） |
| 趋势结构 / ETF | MA 排列、etf 净流 | high |
| 链上 / 订单流 | CVD、netflow、taker | medium~high |
| RSI / MACD 等振荡指标 | rsi_*, macd_* | **medium（且仅在与流动性同向时）；单独出现 = low** |

## 常见矛盾场景及处理规则

### 场景 1：均线空头排列 + RSI 底背离

这是最常见的矛盾。

| 附加条件 | 判断 | confidence_level 上限 |
|---------|------|----------------------|
| + 缩量 + MACD 仍在零轴下 | NEUTRAL | WEAK |
| + 放量 + MACD 零轴下金叉 | 谨慎 LONG | MODERATE |
| + 放量 + MACD 金叉 + CVD 底背离 | LONG | STRONG |
| + 缩量 + 大户比 < 0.8 | SHORT（背离失效） | STRONG |
| + 布林下轨破位 + MACD 死叉 + 新闻偏空 | 禁止 LONG，SHORT/NEUTRAL | MODERATE |

**绝对规则**：均线空头排列中，仅凭 RSI 底背离不得给出 LONG + MODERATE 以上。

### 场景 1b：均线空头排列 + RSI 超卖

复盘显示，单靠 RSI 超卖去抢反弹容易止损。RSI < 30 在下跌趋势中首先应被视为“追空风险”和“等待反弹确认”，不是自动做多信号。

| 附加条件 | 判断 | confidence_level 上限 |
|---------|------|----------------------|
| + MACD 死叉/零轴下 + MA 空头 | NEUTRAL 或 SHORT | MODERATE |
| + 布林下轨破位 + 新闻偏空 | SHORT，但提示反弹风险 | STRONG |
| + 放量收回下轨 + MACD 柱状图连续抬升 | NEUTRAL，等待确认 | MODERATE |
| + 放量收回下轨 + MACD 金叉 + CVD/RSI 底背离 | 谨慎 LONG | STRONG |

**执行规则**：下跌趋势中的 LONG 必须有“买盘介入”证据；只有超卖、恐惧、下轨破位时不得建议加多。

### 场景 2：MACD 金叉 + RSI 超买

| 附加条件 | 判断 | confidence_level 上限 |
|---------|------|----------------------|
| 均线多头排列 + 放量 | LONG（趋势加速） | STRONG |
| 均线多头排列 + 缩量 | NEUTRAL（动能不足） | WEAK |
| 均线空头排列 | NEUTRAL（反弹但不追） | WEAK |

### 场景 3：技术面偏多 + 资金面偏空

技术面偏多：MACD 金叉 / RSI > 50 / 均线多头
资金面偏空：ETF 流出 / 费率极高 / 大户比 > 2.0

| 情况 | 判断 |
|------|------|
| ETF 连续 3 天以上流出 > $200M | 技术信号权重降低，给 NEUTRAL |
| 费率年化 > 30% + 大户比 > 2.0 | 拥挤交易警告，无论技术面多好都不超过 NEUTRAL |
| 仅费率略高 (0.01%~0.03%) | 不影响，维持技术面判断 |

### 场景 4：CVD 背离 vs 价格趋势

CVD 背离是最强的反转预警信号之一。

| CVD 信号 | 价格趋势 | 附加条件 | 判断 |
|---------|---------|---------|------|
| 底背离 | 下跌 | + RSI < 35 + 放量 | LONG STRONG |
| 底背离 | 下跌 | + RSI 40~50 + 缩量 | NEUTRAL WEAK |
| 顶背离 | 上涨 | + RSI > 65 + 缩量 | SHORT STRONG |
| 顶背离 | 上涨 | + RSI 50~60 + 放量 | NEUTRAL WEAK（顶背离可能失效）|

### 场景 5：新闻情绪 vs 技术面

| 新闻 score | 技术面 | 处理 |
|-----------|--------|------|
| > +50 (强利多) | 技术面同方向 | 权重叠加，confidence_level 可上调一档 |
| > +50 (强利多) | 技术面反方向 | 新闻作为风险提示，不改变方向 |
| -50 ~ +50 | 任何 | 新闻仅作为辅助，不纳入主要判断 |
| < -50 (强利空) | 技术面同方向 | 权重叠加 |

### 场景 6：M2 / 稳定币 vs RSI / MACD（流动性优先）

| 流动性（M2 + 稳定币） | RSI/MACD | 处理 |
|----------------------|----------|------|
| 同向扩张/流入 | 任意同向 | 流动性进 key_drivers(high)；RSI/MACD 最多 medium 辅助 |
| 同向扩张/流入 | 反向（死叉/超买等） | **维持流动性方向偏置**；振荡指标写入 risks，不翻转 bias |
| 同向收缩/流出 | 任意同向 | 流动性进 key_drivers(high)；技术面仅辅助 |
| 同向收缩/流出 | 金叉/超卖反向 | 视为反弹噪音；默认 NEUTRAL 或维持空头，禁止因 RSI/MACD 抢多 |
| M2 与稳定币互相矛盾 | — | 以稳定币（更高频、加密原生）为主；M2 作中期背景 |
| 流动性数据缺失 | 仅有 RSI/MACD | confidence_level 上限 CAUTIOUS，且不得给 RSI/MACD high 权重 |

**计数规则**：RSI 与 MACD 合计最多记作 **1 个**同向维度，避免股票型指标刷维度数量。

## confidence_level 校准规则

| 同向信号数量 | confidence_level |
|-------------|-----------------|
| ≤1 个维度 | WEAK |
| 2 个维度 | CAUTIOUS |
| 3 个维度 | MODERATE |
| 4 个维度 | STRONG |
| ≥5 个维度 | VERY_STRONG |

**VERY_STRONG 是最高等级**（≥5 维度同向，极罕见）——市场永远有不确定性。

计维时优先纳入：M2、稳定币、MA/ETF、CVD/净流；RSI/MACD 最多贡献 1 维。

### 方向校准补充（来自近期模拟盘）

- SHORT 顺应 4H 空头结构时，可按正常规则给 MODERATE ~ STRONG；若稳定币仍在流入或 M2 扩张，confidence_level 下调一档并把流动性改善列为主要风险。
- LONG 逆 4H 空头结构时，confidence_level 默认上限 MODERATE；必须有稳定币流入或 M2 扩张之一，再加上放量买盘 / CVD 底背离，才允许提高到 STRONG 下限。仅 MACD 翻转 + RSI 超卖**不够**。
- 若新闻偏空、ETF 连续流出、MA 空头、稳定币流出同时存在，不因 RSI 超卖给 LONG。
- M2 扩张 + 稳定币 strong/moderate_inflow 同向时，即使 RSI/MACD 短暂背离，也不应因此改为 NEUTRAL（除非趋势结构已破坏）。

## 绝对禁止规则

1. 不得仅凭恐贪指数极端值做方向判断（它是左侧指标，不是择时工具）
2. 不得在均线空头排列中仅凭一个反转信号给出 LONG + MODERATE 以上
3. 不得在费率年化 > 30% + 大户比 > 2.0 时给出 LONG + MODERATE 以上
4. 不得忽略成交量——任何没有量能确认的信号，confidence_level 上限为 MODERATE
5. 布林收窄期间不得给出 MODERATE 以上的方向判断
6. 下跌趋势中，不得仅凭 RSI 超卖/恐惧情绪/布林下轨破位建议加多
7. **不得将 RSI 或 MACD 标为 high 权重**；二者单独不得决定 bias
8. **不得用 RSI/MACD 推翻 M2 与稳定币同向的流动性结论**
