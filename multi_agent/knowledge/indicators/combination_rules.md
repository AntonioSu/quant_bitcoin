# 【指标研判 · 组合】矛盾解决与配合规则

## 核心原则

1. **趋势 > 反转信号**：均线方向是基础，反转信号需要多重确认才能推翻趋势
2. **量价 > 纯价格**：任何信号都需要成交量配合验证
3. **多维共振 > 单一极端**：3 个中等强度的同向信号 > 1 个极端信号
4. **资金面验证技术面**：CVD/Taker 确认方向后，技术信号可信度提升
5. **复盘优先修正弱点**：近期 aggressive 模拟盘空单有正贡献，多单逆势抄底亏损；下跌趋势中的 LONG 要比 SHORT 更严格

---

## 常见矛盾场景及处理规则

### 场景 1：均线空头排列 + RSI 底背离

这是最常见的矛盾。

| 附加条件 | 判断 | confidence 上限 |
|---------|------|----------------|
| + 缩量 + MACD 仍在零轴下 | NEUTRAL | 50 |
| + 放量 + MACD 零轴下金叉 | 谨慎 LONG | 60 |
| + 放量 + MACD 金叉 + CVD 底背离 | LONG | 75 |
| + 缩量 + 大户比 < 0.8 | SHORT（背离失效） | 65 |
| + 布林下轨破位 + MACD 死叉 + 新闻偏空 | 禁止 LONG，SHORT/NEUTRAL | 55 |

**绝对规则**：均线空头排列中，仅凭 RSI 底背离不得给出 LONG + confidence > 55。

### 场景 1b：均线空头排列 + RSI 超卖

复盘显示，单靠 RSI 超卖去抢反弹容易止损。RSI < 30 在下跌趋势中首先应被视为“追空风险”和“等待反弹确认”，不是自动做多信号。

| 附加条件 | 判断 | confidence 上限 |
|---------|------|----------------|
| + MACD 死叉/零轴下 + MA 空头 | NEUTRAL 或 SHORT | 55 |
| + 布林下轨破位 + 新闻偏空 | SHORT，但提示反弹风险 | 65 |
| + 放量收回下轨 + MACD 柱状图连续抬升 | NEUTRAL，等待确认 | 55 |
| + 放量收回下轨 + MACD 金叉 + CVD/RSI 底背离 | 谨慎 LONG | 65 |

**执行规则**：下跌趋势中的 LONG 必须有“买盘介入”证据；只有超卖、恐惧、下轨破位时不得建议加多。

### 场景 2：MACD 金叉 + RSI 超买

| 附加条件 | 判断 | confidence 上限 |
|---------|------|----------------|
| 均线多头排列 + 放量 | LONG（趋势加速） | 75 |
| 均线多头排列 + 缩量 | NEUTRAL（动能不足） | 50 |
| 均线空头排列 | NEUTRAL（反弹但不追） | 45 |

### 场景 3：技术面偏多 + 资金面偏空

技术面偏多：MACD 金叉 / RSI > 50 / 均线多头
资金面偏空：ETF 流出 / 费率极高 / 大户比 > 2.0

| 情况 | 判断 |
|------|------|
| ETF 连续 3 天以上流出 > $200M | 技术信号权重降低，给 NEUTRAL |
| 费率年化 > 30% + 大户比 > 2.0 | 拥挤交易警告，无论技术面多好都不超过 NEUTRAL |
| 仅费率略高 (0.01%~0.03%) | 不影响，维持技术面判断 |

### 场景 4：CVD 背离 vs 价格趋势

CVD 背离是最强的反转预警信号之一。

| CVD 信号 | 价格趋势 | 附加条件 | 判断 |
|---------|---------|---------|------|
| 底背离 | 下跌 | + RSI < 35 + 放量 | LONG 70% |
| 底背离 | 下跌 | + RSI 40~50 + 缩量 | NEUTRAL 50% |
| 顶背离 | 上涨 | + RSI > 65 + 缩量 | SHORT 70% |
| 顶背离 | 上涨 | + RSI 50~60 + 放量 | NEUTRAL 45%（顶背离可能失效）|

### 场景 5：新闻情绪 vs 技术面

| 新闻 score | 技术面 | 处理 |
|-----------|--------|------|
| > +50 (强利多) | 技术面同方向 | 权重叠加，confidence +10 |
| > +50 (强利多) | 技术面反方向 | 新闻作为风险提示，不改变方向 |
| -50 ~ +50 | 任何 | 新闻仅作为辅助，不纳入主要判断 |
| < -50 (强利空) | 技术面同方向 | 权重叠加 |

## confidence 校准规则

| 同向信号数量 | confidence 范围 |
|-------------|----------------|
| 1~2 个维度 | 30~50（低信心） |
| 3~4 个维度 | 50~70（中等信心） |
| 5+ 个维度 | 70~85（高信心） |
| 全部维度同向 | 85~95（极高信心，极罕见） |

**永远不要给 100% confidence**——市场永远有不确定性。

### 方向校准补充（来自近期模拟盘）

- SHORT 顺应 4H 空头结构时，可按正常规则给 55~70；若 RSI < 25 或价格远离均线超过 3%，confidence 下调 5~10 分并把反弹列为主要风险。
- LONG 逆 4H 空头结构时，confidence 默认上限 55；只有放量买盘、MACD 翻转、CVD/RSI 背离三者至少满足两项，才允许提高到 60~65。
- 若新闻偏空、ETF 连续流出、MA 空头同时存在，不因 RSI 超卖给 LONG。

---

## 绝对禁止规则

1. 不得仅凭恐贪指数极端值做方向判断（它是左侧指标，不是择时工具）
2. 不得在均线空头排列中仅凭一个反转信号给出 LONG + confidence > 55
3. 不得在费率年化 > 30% + 大户比 > 2.0 时给出 LONG + confidence > 50
4. 不得忽略成交量——任何没有量能确认的信号，confidence 上限为 60
5. 布林收窄期间不得给出 confidence > 55 的方向判断
6. 下跌趋势中，不得仅凭 RSI 超卖/恐惧情绪/布林下轨破位建议加多
